## 開発ドキュメント SSG ツール

ドキュメントをSSGするツール

### 取得後

サンプルのファイル(.docs/*)は削除してください

### saveコマンド

build ~ ローカル git commit コマンドを実行します

```bash
sh _save.sh
```

### 画像の配置方法

docs/1.md を参考に画像リンクをつけ、inputディレクトリに配置

### 依存ライブラリのインストール

```
npm i
```

### 本ツールのアップデート

このツールに更新があった場合、既存ユーザーは `./node/main.js` を置き換えてください
